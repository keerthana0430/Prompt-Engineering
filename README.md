# Qwen Prompting Techniques

A Streamlit-based web application that demonstrates different prompting techniques using the **Qwen Large Language Model (LLM)**.

This project allows users to select a prompting technique, enter a task, customize the temperature and maximum token settings, and generate an AI response. The application also displays the final prompt that is sent to the Qwen model, making it useful for understanding how different prompting strategies affect LLM responses.

---

## Project Overview

Prompting is an important part of working with Large Language Models. The quality and structure of a prompt can significantly affect the generated response.

This project provides an interactive interface to experiment with different prompting techniques:

* Zero-shot Prompting
* One-shot Prompting
* Few-shot Prompting
* Chain-of-Thought (CoT)
* Manual Chain-of-Thought
* Tree-of-Thought (ToT)

The application is developed using **Python** and **Streamlit**, with the project created and tested using **Visual Studio Code (VS Code)**.

---

## Features

### 1. Multiple Prompting Techniques

Users can select different prompting techniques from the dropdown menu.

Available techniques:

* Zero-shot
* One-shot
* Few-shot
* CoT
* Manual CoT
* ToT

Each technique creates a different prompt structure before sending the task to the Qwen model.

### 2. Custom Task Input

The user can enter any task or question in the text area.

Example:

```text
Explain the difference between AI and Machine Learning.
```

The entered task is combined with the selected prompting technique to create the final prompt.

### 3. Temperature Control

The application provides a temperature slider.

Temperature controls the randomness of the generated response.

* Lower temperature → More consistent and focused responses
* Higher temperature → More varied and creative responses

The available range is:

```text
0.0 to 1.0
```

Default value:

```text
0.2
```

### 4. Maximum Token Control

Users can also control the maximum number of tokens generated by the model.

Available range:

```text
100 to 1000 tokens
```

Default value:

```text
500 tokens
```

### 5. Generated Prompt Display

Before displaying the AI response, the application shows the complete prompt generated using the selected prompting technique.

This helps users understand how the selected prompting strategy changes the input given to the LLM.

### 6. Loading Indicator

While Qwen is generating a response, the application displays a loading message:

```text
Qwen is generating the response...
```

This provides a better user experience while waiting for the model response.

### 7. Error Handling

The application uses exception handling to prevent unexpected errors from crashing the interface.

If an error occurs, the application displays an appropriate error message.

# Prompting Techniques

## 1. Zero-shot Prompting

Zero-shot prompting means asking the model to perform a task without providing any examples.

Example:

```text
Explain the difference between AI and Machine Learning.
```

The model receives only the task and generates the response based on its existing knowledge.

### Advantages

* Simple to use
* No examples are required
* Saves prompt space
* Useful for straightforward tasks

---

## 2. One-shot Prompting

One-shot prompting provides the model with one example before asking it to solve a new task.

Example structure:

```text
Example:
Question: What is Python?
Answer: Python is a high-level programming language.

Task:
What is Java?
```

The example helps the model understand the expected format and style of the answer.

---

## 3. Few-shot Prompting

Few-shot prompting provides multiple examples before the actual task.

Example:

```text
Example 1:
Input: 2 + 2
Output: 4

Example 2:
Input: 5 + 3
Output: 8

Task:
Input: 10 + 6
```

The model uses the provided examples to understand the pattern and produce the expected output.

### Advantages

* Helps establish a pattern
* Useful for classification
* Useful for formatting tasks
* Can improve consistency

---

## 4. Chain-of-Thought (CoT)

Chain-of-Thought prompting is a technique designed to encourage the model to reason through a problem step by step.

It can be useful for tasks involving:

* Mathematics
* Logical reasoning
* Problem solving
* Multi-step questions

Example:

```text
Solve the problem step by step and provide the final answer.
```

The application provides the selected CoT technique through the prompt template system.

---

## 5. Manual CoT

Manual Chain-of-Thought prompting provides explicit reasoning instructions inside the prompt.

For example:

```text
Analyze the problem carefully.
Break the problem into smaller steps.
Consider each step before producing the final answer.
```

This approach gives the model a structured way to approach the task.

---

## 6. Tree-of-Thought (ToT)

Tree-of-Thought prompting encourages the model to explore multiple possible approaches or solution paths before selecting an appropriate answer.

It can be useful for:

* Complex reasoning
* Decision making
* Planning
* Problem solving

A simplified structure can be represented as:

```text
              Problem
                 |
        -------------------
        |        |        |
     Path 1   Path 2   Path 3
        |        |        |
     Result   Result   Result
        \        |       /
         \       |      /
          Best Solution
```

Create a Python virtual environment:
